# Askstead 1.1 "Bell" — the product

**One file: [askstead.html](askstead.html).** Open it in a browser — works fully offline. No build, no dependencies, no account.

> **1.1 (2026-07-10):** post-mortem fix — QR codes are now generated by a built-in offline encoder (byte mode, ECC M, versions 1–10). The external QR API is used only as a fallback for links longer than ~213 bytes. Verified: offline-generated QRs at five payload sizes (V2–V10, exercising alignment patterns, version-info blocks, and multi-group Reed-Solomon interleaving) all decode to their exact input via an independent decoder; full 10-assertion app regression green, including a decode of the QR embedded in a real kit.

## What it does
Enter business name + Google review link (+ optional private-feedback email, invitation line, brand color) → **Generate my kit**:
- **Counter card, table tent (fold-ready), 12-up sticker sheet, window poster** — each print-ready via the browser (print stylesheet isolates the asset), QR embedded as a data URI so files are self-contained.
- **Counter page** — a downloadable standalone HTML page showing *every* visitor both "Review us on Google" and "Tell the owner privately" (mailto). Compliant by construction: no gating, no incentives.
- **Ask scripts** — SMS / email / receipt-footer copy with one-click copy buttons.

## Free tier & license
Free: full kit with "Made with Askstead · askstead.com" credit line. Kit License ($49 once per business): removes the credit. Key format `AS1-XXXX-XXXX-XXNN`, NN = (sum of body char codes) mod 97, validated client-side (honor-system, same rationale as Hourstead). Demo key that validates: `AS1-BELL-BELL-BE30`.

Offline QR encoder (top 1.1 item — removes the only network dependency), review monitoring/alerts (needs polling infra), SMS sending (costs money), multi-location management, non-Google platforms (Yelp forbids asking altogether — worth a content page, not a feature).
