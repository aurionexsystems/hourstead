# Proof memo — why Jobfold is worth testing

## What is proven

1. **Pain signal:** several current community discussions describe unpaid or awkward added work and explicitly recommend written, priced change orders before the work begins. See the [evidence dossier](../01-research/EVIDENCE.md).
2. **Workflow fit:** the working app performs the narrow sequence the advice implies: capture request, calculate price/schedule impact, add evidence, record an acknowledgment, print, and back up.
3. **Technical feasibility:** all MVP actions run in one local HTML file with no account or server.
4. **Competitive context:** first-party HoneyBook and Bonsai materials document subscription-based, multi-function alternatives.

## What is not proven

- That contractors will pay $79.
- That a local document changes collection, dispute, or court outcomes.
- That the signature canvas is enforceable in any jurisdiction.
- That this is underserved at scale; the evidence supports a specific workflow pain, not a market-size claim.

## The smallest honest bet

Give away the working builder, then attempt to convert people who repeatedly print/export it. A paid license is the only meaningful early proof. If people use the template but reject the app, simplify toward a printable pack; if people ask for sharing, validate that need before introducing accounts or hosting.
