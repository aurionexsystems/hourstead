# Jobfold product

Open `jobfold.html` directly in a current desktop browser. It is a local prototype: no account, server, analytics, or network request.

## Verified interactions

- Live price calculation: labor + materials + markup.
- Local draft persistence through browser local storage.
- Before/after image selection with on-page previews.
- Mouse/touch signature canvas.
- Print view for browser PDF export.
- Portable JSON job backup download.

## Deliberate boundaries

The prototype documents approval; it does not promise legally binding e-signatures, payment collection, cloud sync, or contractor-law compliance. The research brief explains why those are intentionally out of MVP.
